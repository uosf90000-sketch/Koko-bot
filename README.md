# 👑 كوكو بوت - دليل التشغيل
## مستر يوسف الصبحي

---

## 📁 الملفات:
- `config.py` - الإعدادات (عدّل هنا فقط)
- `main.py` - المشغل الرئيسي
- `alrajhi.py` - فاحص قائمة الراجحي
- `analyzer.py` - محلل الأسهم بالذكاء الاصطناعي
- `trader.py` - منفذ الصفقات
- `reporter.py` - مرسل التقارير

---

## ⚙️ خطوات الإعداد:

### 1. افتح ملف config.py وعدّل:
```
IBKR_USERNAME = "اسم مستخدمك في IBKR"
IBKR_PASSWORD = "كلمة مرورك في IBKR"
EMAIL_PASSWORD = "App Password من Gmail"
TELEGRAM_TOKEN = "Token من BotFather"
TELEGRAM_CHAT_ID = "Chat ID الخاص بك"
```

### 2. رفع على Railway:
1. افتح railway.app
2. New Project → Deploy from GitHub
3. ارفع الملفات
4. البوت يشتغل تلقائياً!
